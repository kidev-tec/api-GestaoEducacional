# Clean-room — distância entre referência e implementação

## Duas trilhas separadas

**Equipe de observação:** entrega necessidade do usuário, fluxo abstrato, regras aparentes, testes de comportamento e oportunidades de melhoria, com grau de confiança.
**Equipe de implementação:** recebe somente requisitos aprovados, fontes públicas/licenciadas e decisão de produto; desenha arquitetura, UI e código originais.

## Proibido transportar

Código de terceiros, dumps, schemas internos não autorizados, logos, ícones, textos distintivos, CSS, assets, scripts de request replay em terceiros, tokens de sessão, IDs privados e segredos.

## Critérios de diferenciação

Novos tokens, componentes, distribuição da navegação, microcopy, design system e fluxos com ganhos observáveis. Cópia de funcionalidade genérica não exige cópia de expressão de marca.

## Checkpoint de revisão

Antes de merge de UX: comparação qualitativa de identidade para detectar cópia visual; antes de API: checar origem de contratos e licenças; antes de migração: somente dados exportados legitimamente pelo cliente.
