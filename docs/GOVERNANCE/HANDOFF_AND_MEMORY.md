# Handoff entre agentes e memória de projeto

A memória real é a coleção versionada em `state/`, nunca uma suposição baseada em conversas anteriores.

Após cada unidade de trabalho, atualizar:
- `PROJECT_STATE.md`: estágio, releases, cards, build real.
- `DECISIONS.md`: decisões aceitas com link para ADRs.
- `OPEN_QUESTIONS.md`: dúvidas que bloqueiam.
- `NEXT_ACTIONS.md`: o próximo passo executável com responsável e gate.
- `HANDOFF_TEMPLATE.md`: mudanças, arquivos, testes, resultado, riscos e problemas.

Não colocar credenciais, dados de alunos, endpoints privados, material de concorrentes ou observações confidenciais brutas em memória. Evidências restritas exigem local seguro e controle de acesso.
