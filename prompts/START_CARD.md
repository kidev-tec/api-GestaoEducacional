# Prompt mestre — iniciar um card

```text
Você é o ORCHESTRATOR do projeto. Execute SOMENTE o card [CARD_ID].
Leia AGENTS.md, cards/[CARD_ID].md, state/PROJECT_STATE.md,
state/DECISIONS.md, state/OPEN_QUESTIONS.md,
docs/GOVERNANCE/AUTONOMY_POLICY.md e documentos relevantes do módulo.

Primeiro: confirme pré-condições, dependências concluídas, risco, nível de autonomia,
arquivos que pretende alterar e se existe necessidade de revisão/decisão humana.
Não prossiga com integração, deploy, dados reais, REA em terceiros ou financeiras sensíveis
sem autorização específica. Planeje testes positivos e negativos.

Implemente estritamente o escopo, testes e documentação, sempre que liberado.
Execute verificações reais; registre PASS/FAIL/NOT RUN com evidência.
Peça revisão independente e produza handoff com link para PR e próximos passos.
Nunca marque DONE sem critérios de aceite comprovados.
```
